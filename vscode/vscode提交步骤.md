# vscode 提交步骤

> 在vscode中操作一次新建文本文件、编写、更改、提交、推送

## 操作步骤

### 1. 新建文本文件

- 启动vscode主程序，左侧“活动栏”点击“资源管理器”，打开学习计划主目录的“文件夹”；
- 在主目录中创建对应子文件夹，本次创建“vscode”文件夹，作为接下来保存相关vscode的笔记和文件；
- 右键点击“对应的笔记文件夹”，点击“新建文件夹”，命名为“vscode”；
- 再右键新创建的“vscode”文件夹，点击“新建文件”，命名为“vscode提交步骤.md“，这里注意直接写上后缀”.md“，markdown的笔记文件就创建好了；

### 2. 编写

- 点击创建好的“vscode提交步骤.md“进入编辑窗口，写入本文件主题”# vscode 提交步骤“，点击“保存”，完成文件的创建和保存；
- 接下来就按照”学习笔记编写规范.md“进行内容编写，编写语言用markdown格式；

### 3. 更改

- 左侧“活动栏”，点击“源代码管理“，在“更改”列表里找到要上传文件；
- 在文件名后有个“+号”按钮叫”暂存更改“，点击+号按钮把文件加入”暂存“列表；
- 文件进入”暂存“列表后不可编辑，若要继续编辑，在”暂存“列表里的文件名后有个”-号“按钮”取消暂存更改“，文件即可返回到”更改“状态；

### 4. 提交

- 文件进入“暂存”状态时，“提交”按钮成就绪状态，即可准备提交；
- 在“提交”按钮上方的文本框内写入本次提交的主要概述，才能正式提交，写入主要概述后点击“提交”；
- 注意：点“提交”只是把这次改动**存在自己电脑上**，还没有到 GitHub。

### 5. 推送

- 提交完，左下角会出现一个带小箭头的圆圈按钮（同步更改），点它；或者在源代码管理面板点“推送”；
- 只有推送完，文件才真正传到 GitHub 网站上；
- 推送成功后，打开 GitHub 网页刷新，看到新文件才算完成。

### 6. 如果推送报错

- `fatal: You are not currently on a branch`：说明没站在分支上（游离状态）。在左下角状态栏点分支名，选回 `main` 再提交推送。
- 其它报错先看 `github/Git报错速查.md`。
  
## 注意事项

- 文件没有进入“暂存”列表，“提交”按钮不可点击；
- 提交说明（Commit message）必须写，不然过几天自己也看不懂这次改了什么；
- “提交”和“推送”是两件事：提交=存本机，推送=传上网。
