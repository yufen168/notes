# vscode 提交步骤

> 创建一个全新文本文件，格式为markdown，新建、编写、更改、暂存、提交、推送。

## 操作步骤

### 1. 新建文本

- 启动vscode主程序；
- 左侧”活动栏“点击”资源管理器“，选择“新建文本文件”，创建全新文本文件；
- 在全新文本文件中写入“# vscode 提交步骤”的文件主题名；
- 保存这个文本文件，文件名就用文件主题名，文件格式选择“markdown“，后缀”.md"；

### 2. 编写文本

- 按照“学习笔记编写规范.md”的要求，编写文本内容，并保存文件；

### 3. 更改

- 左侧“活动栏”点击“源代码管理“，在“更改”列表找到主题文件”vscode提交步骤.md“；
- 点击文件名后，可以继续编辑、保存这个文本文件；

### 4. 暂存

- 在该主题文件名后端有一个“+号”按钮叫“暂存更改”；点击按钮后即可把文件列入“暂存的更改”列表，这个时候就可以提交github了；

### 5. 提交

- 当文件进入“暂存的更改”列表时，可以看到“提交”按钮已经就绪可点击；
- 在“提交”按钮上方的文本框中写入本次提交的主要概述，例如”调整结构、新增操作步骤“，以提示本次提交的文件主要做了什么；

### 6. 推送

- 完成提交后，vscode就会将对应文本文件同步提交到github了。

## 注意事项

- 当文件进入“暂存的更改”时，文件不可编辑，若要编辑，先点击“-号”按钮“取消暂存更改”后，在“更改”列表下就可以编辑；
- 文件必须进入“暂存的更改”状态下，才能启动“提交”按钮；
- 每次提交必须写入“主要概述”才会被推送。
