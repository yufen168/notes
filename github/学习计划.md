## 现在在哪

第 1 关收尾。仓库已经推上去过，笔记也归好位了，就差**用图形界面把改动提交并推上去**这一次实操。

## 第 1 关：改了就得传

- **要会的事**：工作区改了文件 → 暂存 → 提交（写说明）→ 推送。还有换设备前先拉取。
- **怎么练**：随便改一句话 → 打开源代码管理面板 → 点 `+` 暂存 → 写说明 → 点 `✓` 提交 → 点同步推上去。去 GitHub 网页刷新，看见改动才算数。
- **怎么算过关**：不看笔记，独立完成一次「改 → 提交 → 推送」，网页上能看到。
- **笔记**：`github/VS Code图形提交步骤.md`（做完再写，写你实际点的按钮顺序）

## 第 2 关：改错了怎么救

- **要会的事**：看两个版本的差别（Diff）、看历史记录、把文件恢复到上次提交的样子、把整个仓库退回到某个版本。
- **怎么练**：故意改坏一个文件 → 在源代码管理里点开那个文件看红绿对比 → 用「放弃更改」救回来。再去网页的 History 里找到上一次提交看看。
- **怎么算过关**：能说清「红的是删掉的、绿的是新加的」，并且能安全救回一个改坏的文件。
- **笔记**：`github/改错了怎么救.md`

## 第 3 关：分支（一个人也值得用）

- **要会的事**：开一个分支写新东西，试完不满意就扔掉，满意就合并回主线。主线永远是能看的版本。
- **怎么练**：从 `main` 开一个 `练习` 分支 → 在里面建一个废文件 → 提交 → 切回 `main`（发现废文件不见了）→ 把分支删掉。
- **怎么算过关**：能来回切换分支、能删分支，主线不受影响。
- **笔记**：`github/分支怎么用.md`

## 第 4 关：冲突长什么样

- **要会的事**：同一个文件的同一行，两处都改过，Git 会卡住让你选。要认识那堆 `<<<<<<<` 符号，手动选留哪句。
- **怎么练**：在网页上改一行 → 本地不同步也改同一行 → 本地提交后推送 → 会报冲突 → 按提示先拉取，再手动留一句、删掉符号，重新提交推送。
- **怎么算过关**：自己造一次冲突，自己解开。
- **笔记**：`github/冲突怎么解.md`

## 第 5 关：网页上能干的事

- **要会的事**：不用本地电脑，直接在网页上改文件、提 Issue 记待办、Star 收藏别人的仓库、Fork 复制别人的仓库到自己名下。
- **怎么练**：在网页上给本仓库开一个 Issue，写下一条想学的东西；再在自己仓库里用网页改一个字并提交。
- **怎么算过关**：网页端能改文件、能开 Issue 并关掉它。
- **笔记**：`github/网页端操作.md`

## 第 6 关：把笔记变成网页

- **要会的事**：用 GitHub Pages 把 `README.md` 变成一个能发给别人的网址。
- **怎么练**：仓库设置里找到 Pages，选 `main` 分支，等一分钟，拿到网址，手机打开看看。
- **怎么算过关**：手机上能打开你自己的笔记网址。
- **笔记**：`github/笔记变网页.md`
